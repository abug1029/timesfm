# oi_gated_momentum 协变量 Spec（v23 口径）

> 日期: 2026-09-18。来源: backlog 评审 `oi_weighted_momentum`（2026-09-18 凌晨收录）
> 的 scaling_factor 方案 + 公式结构修正方案。状态: **spec 编制，未实施**。
> 决策: 采用**方案一（滚动分位数目标激活度定标）** + **门控结构修正**。

## 1. 背景与决策

backlog 提案 `oi_weighted_momentum`（豆粕 m，momentum 族）机制成立，但存在两类缺陷：
scaling_factor 无定标规则（参数挖掘自由度），且 tanh 作用于价格×持仓**乘积**与机制
假设背离——异号乘积输出为负，减仓行情不但不衰减至零，反而发出反向信号（"反向反手
开仓"缺陷，详见 §2.1）。

本 spec 采纳宿主评审结论：
1. **定标采用方案一**：滚动分位数自适应定标，冻结人为常数自由度；
2. **结构修正**：价格与持仓解耦，持仓项仅作非负门控，方向由价格单独决定；
3. **数据口径**：ΔOI 必须用全市场总持仓，杜绝主力换月污染；执行侧强制 T-1 滞后。

## 2. 信号定义

### 2.1 原公式缺陷（修正依据）

| 行情 | ΔP | ΔOI | 乘积符号 | 原公式输出 | 机制预期 |
|---|---|---|---|---|---|
| 增仓上涨 | + | + | + | tanh(+) 做多 | ✅ 符合 |
| 减仓上涨 | + | − | − | tanh(−) **做空** | ❌ 应衰减至 0 |
| 增仓下跌 | − | + | − | tanh(−) 做空 | ✅ 符合 |
| 减仓下跌 | − | − | + | tanh(+) **做多** | ❌ 应衰减至 0 |

原公式实为"价仓同向顺势、背离反手"的振荡逆转策略，与"以增仓为量价验证门控的动量"
机制相反。

### 2.2 修正后信号（唯一正式定义）

$$
\text{Signal}_t = \tanh(\Delta P_{5d,t} \times \text{scale}_{P,t}) \times \max\bigl(0,\ \tanh(\Delta OI^{tot}_{5d,t} \times \text{scale}_{OI,t})\bigr)
$$

- **方向由价格单独决定**：tanh(ΔP×scale_P) 是有符号主项；
- **持仓项是非负门控**：max(0,·) 半波整流截断门——增仓时激活（0→1 渐变），
  减仓时**精确归零**。四象限行为与机制表完全一致。

**门控选型决策（冻结）**：选半波整流截断门，**不选 sigmoid**。理由：sigmoid 门在
减仓时仍输出正权重（只趋向 0 不到 0），会给"减仓行情"保留信号权重，违背机制表格
中"减仓→衰减至零"的明确语义。门控语义优先于平滑性。

### 2.3 方案一定标（对原方案的必要适配）

原方案一写作 `scale = 1/RQ_K(|raw_interaction|, 0.75)`，作用对象是**乘积**。结构
解耦后乘积项不复存在，故将同一规则**分别应用于两个因子**（这不是引入新自由度——
两处用完全相同的规则参数，规则本身无待调常数）：

$$
\text{scale}_{X,t} = \frac{1}{\text{RollingQuantile}_{K}\bigl(|X|,\ 0.75\bigr)\text{ 于窗口 }[t-K,\ t-1]}
$$

- K = **120 交易日**（固定，中长期），q = **0.75**（固定）；
- **严格单向滞后一期**：窗口截止 T-1，绝对不含 T（前视防护，见 §3.2）；
- 效果：|X| 的 75% 历史分位被映射到 tanh 饱和拐点（tanh(1)≈0.76），典型波动落在
  弹性过渡带，不同波动率时期激活敏感度稳定；
- **实证量级（豆粕 m，2016→2026，全库计算）**：|ΔP_5d| p75 = 2.94%（评审估计
  1~5% ✅），|ΔOI^tot_5d| p75 = 12.15%（评审估计 3~15% ✅）。对应 scale_P ≈ 34、
  scale_OI ≈ 8.2（滚动时变，此处仅静态验证量级）。

## 3. 数据工程守则（防虚假阿尔法）

### 3.1 总持仓口径（数据前提，当前不满足——必须先补数）

**实证**：`futures_m.db` 的 `kline_1d` 仅含 1 个合约代码 `M_CONT`（TqSdk 主力连续
直连入库，`data/main_chain.py` 已标注 DEPRECATED：采集切换为 KQ.m@ 直连）。**库中
不存在分合约数据，主力单合约 OI 的 ΔOI_5d max = 154%**（换月翻倍特征），换月污染
是现实而非假设。

**解决路径**：新增摄入 **TqSdk 指数合约 `KQ.i@m`** 的日线（其 open_interest 天然
等于全市场各合约总持仓，无需逐合约抓取）。要求：
- 回填 2016-01-05 → 至今（与现库对齐），入新表 `index_continuous_1d`
  （dt, close_price, volume, open_interest），每日增量同步；
- 模块对数据源无感知，只接受 `total_oi` 序列。

### 3.2 时序对齐（T-1 滞后）

官方持仓 T 日数据在 T 日收盘结算后才发布。日频收盘信号只允许使用 **≤ T-1** 的
持仓数据；滚动分位数窗口同样截止 T-1。价格可用 T 收盘（收盘前调仓场景下价格用
T-1 收盘，与现有协变量口径保持一致，见 §5 输出契约）。

### 3.3 数值卫生（项目惯例）

- 输入 NaN/inf/非数值（含 bool）→ 输出 NaN，**fail-closed**，由下游硬门拒绝，
  不做静默填充；
- 回测窗口起点前 K=120 日为定标预热期，输出 NaN；
- ΔP/ΔOI 5 日窗口不足 → NaN。

## 4. 模块设计

- **路径**：`cascade/oi_gated_momentum.py`（独立模块，纯函数、无 I/O、确定性可复现）
- **API**：

```python
def compute_oi_gated_momentum(
    price: pd.Series,        # 日收盘价 (index=DatetimeIndex, 由调用方保证对齐)
    total_oi: pd.Series,     # 全市场总持仓 (KQ.i@m 口径, T-1 滞后由本模块内部 shift)
    k: int = 120,            # 定标窗口, 默认冻结
    q: float = 0.75,         # 分位数, 默认冻结
) -> pd.Series:
    """返回日频信号序列, float, NaN=不可用 (fail-closed)"""
```

- **内部强制 shift(1)**：total_oi 与滚动分位数窗口的 T-1 滞后在模块内实现，
  调用方无需（也不得）自行滞后——杜绝调用侧前视；
- **调用方**：`scripts/extract_xreg.py` 协变量注册 + cascade 特征流水线（慢环
  aligned 评估消费）；快环经 covariate menu 的机制说明引用本 spec，不直接调用；
- 参数 k/q 有默认值但**视为冻结常量**：不允许运行时注入覆盖，慢环无调参自由度。

## 6. 验收清单（实施时逐项检查）

1. 模块级测试：
   - 门控四象限表逐格断言（§2.1 的四行情 → 输出符号/零，与机制预期一致）；
   - 无前视测试：t 期输出对 t 期 total_oi 扰动不敏感、对 t-1 期扰动敏感；
   - NaN/inf/bool 输入传播为 NaN；预热期（前 K 日）输出 NaN；
   - 确定性：同输入两次调用逐位相等。
2. 数据级验收：`index_continuous_1d` 覆盖 2016-01-05→今且 OI 无空洞；换月日
   （对比主力单合约序列）ΔOI 无翻倍跳变。
3. 集成验收：extract_xreg 注册后，慢环 aligned eval 能消费该协变量（复用现有
   硬门/软门，无评估器改动）。
