## 6. 附带新发现 I：detection_threshold_vs_baseline 缺 /n

- 实现 `se_hac = sqrt(compute_hac_se(d))` → 门槛 = 1.645·σ_LR（**逐点**标度）；spec §8.3 与其自身黄金例（rho=0.5、n=588 → 0.096 = 1.645×√(0.25×8.028/588)）要求 SE(d̄)=√(σ_LR²/n)。同文件 DM 实现正确除以 T（「再除以 T 得均值方差」）。
- 测试掩盖机制：黄金测试用稀疏构造（588 点中 2 点非零，γ₀=2/588≈0.25×8.028/588）使错误公式恰好命中 0.096。
- 影响面：**零生产调用**（evaluator.py:26 import 未用；仅 registry_lib 字段名清单与 readiness 黄金断言引用名字）→ 无存量结果污染，**不需搭 v4 指纹波**。
- 处置：计划新增 **2.10**——修函数（除以 n）、黄金测试改 spec 真实构造（rho=0.5 AR(1)，断言 0.096 不变）、evaluator 死 import 随 2.6 接线一并处置。
