3. **趋势改善**：9月→10月，gate pass 率提升 5.6%，S/A 占比提升 3.0%
4. **品种/协变量差异显著**：可聚焦高表现品种（ta, sh, ao）和协变量族（momentum, term_structure）

### 关键问题

1. **dir_acc 均值 0.4429 低于 0.50**：
   - 原因：C + D tier（43.0%）的 dir_acc < 0.36，拉低整体均值
   - 解决：通过 gate 机制过滤，只关注 S/A/B tier（57.0%），其 dir_acc 均值 0.52

   - Laya 服务 0% success，无法过滤低质量提案

   - ta/sh/ao 表现优异，jd/ma/eg 表现差
   - momentum/term_structure 表现好，volatility 表现差
   - 解决：优先探索高表现品种和协变量族
