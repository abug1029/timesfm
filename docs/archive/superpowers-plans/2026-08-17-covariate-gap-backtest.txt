# 协变量空白补测 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 对 20 品种中测试不足/从未测试的协变量×品种组合进行系统性补测，填补 141 次回测中的空白区域，寻找可改善 PF/DirAcc 的新组合。

**Architecture:** 基于 `scripts/monthly_backtest.py` 的 `--combo` / `--cov-override` CLI 接口，按优先级分批执行完整 396pt walk-forward 回测。每批次用 nohup 脱机运行 + JSONL 断点，结果写 `reports/monthly_backtest/` 并更新 `docs/backtest_registry.md`。

**Tech Stack:** Python + TimesFM 2.5 (CPU-only) + SQLite + JSONL checkpoint

**Spec:** 本次分析的梳理结果（上一轮对话的"协变量穷举历史总梳理"）

## Global Constraints

- **回测前先获用户批准**（2026-08-05 用户指令）
- CPU-only 环境，单品种 396pt ≈ 30-60 分钟
- 长时任务用 nohup + JSONL 断点续跑（SOP: `long-task-sop-windows.md`）
- `PYTHONIOENCODING=utf-8` 防 GBK 崩溃
- 禁止用 3pt/7pt scan 代替完整 WF 回测（2026-08-03 用户指令）
- 单写入者约定：同一 JSONL 同时只允许一个进程追加
- 评估口径：v2 verdict（PF +10% 或 MaxDD 改善 + EV 不恶化）

| 第 1 天 | A (3 回测) | ~2.5h | 先跑 SS 验证 + UR 增强 |
| 第 1 天夜间 | B (3 回测) | ~2.5h | nohup 脱机，次日收结果 |
| 第 2 天 | C (3 回测) | ~2.5h | sar_dist 在 ha_body 体系的表现 |
| 第 2 天夜间 | D (3 回测) | ~2h | 补测不足品种 |

**总计约 3 天可完成全部 15 次回测 + 裁决。**

## 风险与备选

1. **sar_dist 全 FAIL**: 说明 Parabolic SAR 对期货 1H 预测无价值，从候选池永久移除。这是有价值的负结论。
2. **SS reversal_shadow 验证 FAIL**: 当前固化方案在新口径下不达标，需要回到 Task B 的 rsi_state+sar_dist 或其他组合。
3. **CPU 时间不足**: 可先跑批次 A+B（6 回测，~5h），根据 sar_dist 首测结果决定是否继续批次 C。
4. **数据 stale**: 任何品种数据过期会阻断回测，预检时一并补采。
