## ⚠️ 前视修复（本报告写就后新增）

本报告写就后（`d5cebf0` 之后）发现并修复了**回测 1-bar 前视**：
`BacktestDataStore` 用 `dt <= cutoff_ts` 截断，而 `cutoff = dt[idx]+1h`
恰等于 `dt[idx+1]` —— 模型看到预测目标第一根的收盘价。
修法 `_h1_upper_bound = cutoff_ts − 1h`（commit `968945f`）。

**后果**：模型输入已改变 → 本报告中的所有评估结论对应的数据前提
**已失效**，全部 baseline 需重跑，nocov 基线/配对交集/DM 序列/
